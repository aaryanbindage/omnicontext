description: Sync your OmniContext memory with your other devices now
---
Call the omnicontext `sync_now` tool and report the result in one line. If sync isn't configured, tell the user to run `omnicontext sync --github` (creates a private GitHub repo with the gh CLI) or `omnicontext sync --remote <git-url>`, or to use the OmniContext desktop app's Sync tab.

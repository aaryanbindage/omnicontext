About me

Every Claude session on every device reads this. Markdown.

Projects

Give each project nicknames so “my game project” resolves anywhere.

    Select or create a project.

    Notes

      Add a project or a fact and it shows up here.

      Drag to move · scroll to zoom · click a node for details. Projects link through their tags, devices and handoffs, and whenever one is named in a note, fact or handoff. Write [[Topic]] in any note to link a topic.

      Handoffs

      Work saved in one session to resume anywhere. In Claude Code: /omnicontext:handoff and /omnicontext:resume.

      Inbox

      Quick captures from the Apple Watch app, the CLI (omnicontext capture) or Claude. File each one as a profile fact or a project note. Claude also offers to do this at the start of a session.

      Set up sync
      
        
      Easiest: create a private GitHub repo (needs the GitHub CLI logged in).
      
        
      
        
      Or use any git remote you own (GitHub, GitLab, Gitea, a server…). On your other devices, connect the same URL.
      
        
      
      
      
      
      
        
      Apple Watch
      
        
      The standalone watch app reads your GitHub data repo directly, with no phone needed. You can check handoffs, projects and your profile, and dictate captures into the inbox. Set it up.
      
      
      
      
      
        
      Backup
      
        
      Everything in one JSON file. Import merges it into this device's memory.
      
        
      
      
      
    
      

    
      
      
      Connect agents
      Install once per device. Claude, Codex, Cursor and Gemini all share the same memory, so a handoff saved in one can be resumed in another.
      
      
      
        
      Claude Code
      
        
      Plugin: injects your context at session start, adds /omnicontext:handoff, /omnicontext:resume, /omnicontext:remember, /omnicontext:project, and syncs on exit. Requires Node.js 18+.
      
        
      
        
      /plugin marketplace add aaryanbindage/omnicontext
/plugin install omnicontext@omnicontext
      
      
      
      
      
        
      Claude Desktop
      
        
      Adds the OmniContext MCP server to . Restart Claude Desktop afterwards.
      
        
      
      
      
      
      
        
      OpenAI Codex
      
        
      Adds the MCP server to ~/.codex/config.toml (used by the Codex CLI, IDE extension and app) and memory instructions to ~/.codex/AGENTS.md. Requires Node.js 18+. Or install the plugin: codex plugin marketplace add aaryanbindage/omnicontext.
      
        
      
      
      
      
      
        
      ChatGPT
      
        
      ChatGPT can only reach servers on the internet, so this shares your memory through a private link (a Cloudflare tunnel) while this app is running. In ChatGPT: Settings → Apps & Connectors → Advanced → Developer mode, then Create with the link below and No authentication. Requires Node.js 18+.
      
        
      Anyone with the link can read and write your memory, so keep it to yourself. The link changes each time the app starts; paste the new one into ChatGPT.
      
        
      
        
      
      
      
      
      
        
      Cursor and Gemini CLI
      
        
      Adds the MCP server to ~/.cursor/mcp.json or ~/.gemini/settings.json (plus GEMINI.md instructions). Requires Node.js 18+.
